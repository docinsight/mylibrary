TObjectArrayList<T> Class

Definition

Unit:
MyLibrary.Collections.Lists

Provides a resizable array-backed list for object references.

Remarks

When OwnsObjects is true, the list frees contained objects when they are removed, deleted, cleared, or when the list is destroyed. Assigning a new value through the inherited Items property does not free the object being replaced.
